# reDMP2 v0.0.9

Adds autoplay toggled from the OSD menu (the same feature as reDMP1 #59).

Issue [#17](https://github.com/reexec/reDMP2/issues/17):

- DMP2 memory layout analysis (`docs/analysis/autoplay.md`): pad, mode byte and key configuration table, judgement function, play scene and its judgement, score and gear objects, chart and notes, long notes, analog lane.
- Input-stage autoplay (`src/app/autoplay.{h,cpp}`, repsp `SetButtonFilter`):
  - reads the key configuration table on every call, so user key changes are followed
  - holds long notes to their end
  - when turned on mid-song, skips notes already judged
- OSD Input tab `Autoplay` (off at each start, not saved), an `AUTOPLAY` badge during play, `--autoplay`.
- `redmp2_autoplay_probe`.
- Diagnostic `REDMP2_MEM_DUMP` / `REDMP2_MEM_DUMP_VBLANK` (off by default).
- Verified: 4B and 6B with BREAK 0; 5B with BREAK 3 (three analog-lane notes, not yet supported).
- Squashed into this release's merge commit.

Verified: CTest 34/34 on Win64 Release with generated code, passing on Debug/Release without it, zero warnings. User check in windowed mode (OSD toggle, audio fine). Linux x64 in CI.
