# reDMP2 v0.0.2

Pins repsp v0.0.30; `BOOT.BIN` now loads and enters guest execution.

Issue [#3](https://github.com/reexec/reDMP2/issues/3):

- `third_party/repsp` moves to v0.0.30 (`81558ef`, [reexec/repsp#65](https://github.com/reexec/repsp/issues/65): fixed-address `ET_EXEC` loading).
- First runtime boot measurement: the image loads at `0x08804000..0x08E2A500`. `module_start` starts at entry `0x0880FC4C` and stops with class (b), unimplemented NID, at its first import call, `SysMemUserForUser` `0x7591C7DB` (`sceKernelSetCompiledSdkVersion`).
- Updated `docs/analysis/boot.md`, `EXECUTABLE_DESIGN` and the work log.
- Squashed into this release's merge commit.

Known issue: the local CTest test that needs game data, `app_smoke_registered_roms`, fails on that stop (`app_lift_check` now passes). Follow-up: boot-path HLE in repsp.

Verified: CTest 30/30 on Win64 Debug/Release without generated code (the CI condition), 31/32 on Release with generated code. Linux x64 in CI.
