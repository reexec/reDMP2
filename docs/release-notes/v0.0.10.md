# reDMP2 v0.0.10

Autoplay now also hits notes on the analog-stick lane.

Issue [#19](https://github.com/reexec/reDMP2/issues/19):

- Analog-lane analysis (`docs/analysis/autoplay.md` §6): it is a wiggle input, not a direction. Each direction change adds 1 to a counter and sets a timer to 30; judgement checks counter `!= 0`.
- Autoplay sets buttons and stick together through repsp `SetSampleFilter`:
  - right on the note frame
  - long notes alternate left and right until their end
  - taps return to neutral on the next call
  - neutral before a note
- `third_party/repsp` → v0.0.36 ([reexec/repsp#77](https://github.com/reexec/repsp/issues/77)).
- 5B `sO mUCH iN LUV` NM with BREAK 0; 4B and 6B with BREAK 0.
- Limit: with very slow frames (mean about 65 ms), dense notes can be missed.
- Squashed into this release's merge commit.

Verified: CTest 34/34 on Win64 Release with generated code, 10/10 on Debug/Release without it, zero warnings. User check in windowed mode. Linux x64 in CI.
