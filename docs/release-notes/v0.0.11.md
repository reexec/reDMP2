# reDMP2 v0.0.11

Splits `roms/` per disc ID, as groundwork for link disc (UMD swap).

Issue [#21](https://github.com/reexec/reDMP2/issues/21):

- Layout: `roms/ULKS46116/` (DMP2, required); `roms/ULKS46050/` and others (link discs, optional).
- One disc-selection rule is shared by the app (`IdentifyGameDirectory`) and the scripts (`scripts/recomp/disc_resolver.py`, used by `regenerate.py`, `register_disc.py`, `tools/import_coverage.py` and the CMake tests):
  - a disc folder is used as is
  - for a folder of discs, `PARAM.SFO` is read, the registered disc (DMP2) becomes the main disc, and the others are recorded as link disc candidates
  - empty or unreadable folders are skipped
- `redmp2.exe roms`, `redmp2.exe roms/ULKS46116` and the old layout all work.
- README, `ARCHITECTURE.md` and guides updated.
- Squashed into this release's merge commit.

Verified: lift figures (7,982 functions, 28,109 entries), `lift_audit` 0/0 and static match 163/229 are unchanged. CTest 34/34 on Win64 Release with generated code, 9/9 on Debug/Release without it, zero warnings. Linux x64 in CI.
