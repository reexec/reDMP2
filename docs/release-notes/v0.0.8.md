# reDMP2 v0.0.8

The song list text on the song select screen now renders correctly.

Issue [#15](https://github.com/reexec/reDMP2/issues/15):

- `third_party/repsp` → v0.0.35 ([reexec/repsp#75](https://github.com/reexec/repsp/issues/75)): DXT5 alpha index bit order fixed, plus an optional GE trace `REPSP_GE_TRACE`.
- The list is a DXT5 texture, and the cause was repsp's decoder, not the guest data or the lift.
- Confirmed both headless and in windowed mode.
- Squashed into this release's merge commit.

Verified: song select reproduced on the FFmpeg-plugin Release build; user check in windowed mode. Win64 Debug/Release without generated code and Linux x64 in CI.
