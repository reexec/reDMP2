# reDMP2 v0.0.5

The boot now gets past the opening movie, through the first-run path (no savedata → language select → profile creation → autosave), to the title screen.

Issue [#9](https://github.com/reexec/reDMP2/issues/9):

- Local psprecomp patch `0011`: lui+addiu/ori pairs are found by register tracking (up to 16 instructions) instead of a fixed 4-instruction window (`ET_EXEC` only; PRX unchanged).
- The missing allocation and free callbacks (`0x08817218`, `0x08817228`) are lifted. Functions 7,978 → 7,982; `lift_audit` 0/0; reDMP1's result is unchanged.
- `third_party/repsp` → v0.0.33 ([reexec/repsp#71](https://github.com/reexec/repsp/issues/71): `sceIoCloseAsync`, `sceRtcGetCurrentClockLocalTime`, `sceIoGetstat`). Static match 161/229.
- With an input script, 2,400 vblanks present 1,082 frames; the last is the title screen, waiting for input.
- Squashed into this release's merge commit.

Verified: CTest 32/32 on Win64 Release with generated code, zero warnings. Win64 Debug/Release without generated code and Linux x64 in CI.
