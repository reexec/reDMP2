## 1. 업스트림 ABI 변경점 확인 (`5ca18fa..14749c1`)

`git -C third_party/psprecomp diff 5ca18fa 14749c1 -- include/psprecomp/cpu.h src/dispatch.c src/vfpu.c`로 런타임 ABI 변경을 점검했습니다.

* `include/psprecomp/cpu.h`, `src/vfpu.c`: **변경 없음**.
* `src/dispatch.c`:
  * **PR #32 (호출자 프레임 경량화)**: `PSP_NOINLINE` 헬퍼 `psp_call_guest_fn(psp_func_t fn, uint32_t target_addr)`와 `psp_call_guest_addr(uint32_t target_addr, uint32_t call_site_addr)` 추가. 생성 코드의 `jal` / `jalr` / 임포트 호출마다 `$sp` 백업·호출·`PSP_SP_CALL` 검증과 호출자 프레임 프로로그 부담을 헬퍼 안으로 옮겨 Debug 빌드 스택 오버플로 위험을 제거합니다.
  * 다중 슬롯 워치포인트(`psp_trace_watch*`, `psp_trace_watch_label*`): `reDMP2`는 `psp_trace_*` 경로를 사용하지 않으므로 이식하지 않았습니다.

## 1. Upstream ABI Diff (`5ca18fa..14749c1`)

Checked `git -C third_party/psprecomp diff 5ca18fa 14749c1 -- include/psprecomp/cpu.h src/dispatch.c src/vfpu.c`:

* `include/psprecomp/cpu.h` and `src/vfpu.c`: **no changes**.
* `src/dispatch.c`:
  * **PR #32 (caller frame size reduction)**: Added `PSP_NOINLINE` helpers `psp_call_guest_fn(psp_func_t fn, uint32_t target_addr)` and `psp_call_guest_addr(uint32_t target_addr, uint32_t call_site_addr)` to move `$sp` save/check and call overhead out of lifted callers, eliminating Debug-build stack overflow risk.
  * Multi-slot watchpoints (`psp_trace_watch*`, `psp_trace_watch_label*`): not ported because `reDMP2` does not use the `psp_trace_*` path.
