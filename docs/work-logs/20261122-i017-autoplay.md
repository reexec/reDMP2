## 1. 단위별 변경 요약

### 1단계: 분석 및 진단 환경 변수
* `src/app/main.cpp` (`4e3a711`): 기본 꺼짐인 `REDMP2_MEM_DUMP` / `REDMP2_MEM_DUMP_VBLANK` 환경 변수를 추가해 지정한 vblank에 유저 RAM(`0x08800000`, 24 MiB)을 1회 덤프할 수 있게 했다.
* `docs/analysis/autoplay.md`, `docs/analysis/README.md` (`9bc08bb`): 생성 코드와 4B `Ladymade Star` NM vblank 4200 라이브 덤프를 대조해 패드, 모드·키 설정 표(`0x089756D0`), 판정(`0x0885829C`), `PlayScene` (`*0x08972980`, vtable `0x088D10C4`), `G`/`S`/`gear`/`C` 포인터 체인, 채널 배열(`C + 8368 + ch * 12`, `+4`가 `count`), 노트 형식(`+14` `u16` `duration >= 7` 롱노트)을 확인하고 기록했다.

### 2단계: 자동 플레이 구현, OSD/CLI 연결 및 문서
* `src/app/autoplay.h`, `src/app/autoplay.cpp`, `src/app/autoplay_probe.cpp`, `CMakeLists.txt` (`60580d9`):
  * `redmp2::app::autoplay_layout` 네임스페이스에 DMP2 전용 주소·오프셋을 모으고 생성 코드 및 측정 근거를 주석으로 남겼다.
  * 설계 §4.1 결정을 반영했다:
    * 매 호출 모드 바이트(`0x0897298D`)와 라이브 키 설정 표(`0x089756D0 + mode * 11`)를 읽어 버튼 레인을 계산해 사용자 키 변경을 그대로 따른다.
    * 5B 중앙 레인은 `[2]`로 누르며, 사람 입력 제거 마스크에는 `[2]`와 `[3]`을 모두 포함한다.
    * 채널 배열은 `C + 8368 + ch * 12`에서 `+0 begin`, `+4 count`로 읽는다.
    * 아날로그 레인(`gear + 5756 - 1`)은 이번 범위에서 다루지 않되, 해당 채널에 플레이 노트(`type == 1`)가 있으면 곡마다 한 번 `stderr`로 로그를 남긴다.
  * `redmp2_autoplay_probe`를 추가해 비플레이 장면 무변경, 4B/5B/6B/8B 배치, 5B `[3]` 제거 및 사용자 키 변경 추종, 단타 1프레임 누름·해제, 연속 노트, 롱노트 유지·해제, 일시정지 복귀를 합성 게스트 메모리로 검증했다.
* `src/app/settings_ui.h`, `src/app/settings_ui.cpp`, `src/app/main.cpp` (`a532389`):
  * `Input` 탭 맨 위에 `Autoplay` 체크박스와 안내 문구를 추가하고, 켜져 있고 플레이 장면인 동안 화면 오른쪽 위에 `AUTOPLAY` 배지를 표시하도록 했다(매 실행 꺼짐, `redmp2.ini` 미저장).
  * `--autoplay` 명령줄 옵션을 추가하고 `repsp::hle::ctrl::SetButtonFilter`에 연결했다(종료·오류 경로에서 `nullptr` 해제).
* `README.md` (`e9e57c5`): 한국어·영어 문서에 `Input` 탭 `Autoplay`, `AUTOPLAY` 배지, `--autoplay`, 진단 환경 변수 `REDMP2_MEM_DUMP` / `REDMP2_MEM_DUMP_VBLANK`를 반영했다.

## 1. Summary of Changes by Unit

### Phase 1: Analysis and Diagnostic Env Var
* `src/app/main.cpp` (`4e3a711`): Added optional (off by default) `REDMP2_MEM_DUMP` and `REDMP2_MEM_DUMP_VBLANK` environment variables to dump guest user RAM (`0x08800000`, 24 MiB) once at a target vblank.
* `docs/analysis/autoplay.md`, `docs/analysis/README.md` (`9bc08bb`): Confirmed pad buffers, mode & live key-config table (`0x089756D0`), judgement (`0x0885829C`), `PlayScene` (`*0x08972980`, vtable `0x088D10C4`), `G`/`S`/`gear`/`C` pointer chain, channel arrays (`C + 8368 + ch * 12`, `+4` is `count`), and note format (`+14` `u16` `duration >= 7` for long notes) from generated code and the 4B `Ladymade Star` NM vblank 4200 dump.

### Phase 2: Autoplay Implementation, OSD/CLI Wiring, and Docs
* `src/app/autoplay.h`, `src/app/autoplay.cpp`, `src/app/autoplay_probe.cpp`, `CMakeLists.txt` (`60580d9`):
  * Consolidated DMP2-specific addresses and offsets in `redmp2::app::autoplay_layout` with generated-code and memory-dump comments.
  * Implemented the phase 1 review decisions (§4.1):
    * Reads the mode byte (`0x0897298D`) and live key-config table (`0x089756D0 + mode * 11`) on every call so user key remappings are followed automatically.
    * Presses `[2]` for the 5B center lane and clears both `[2]` and `[3]` from human input.
    * Reads channel arrays at `C + 8368 + ch * 12` using `+0 begin` and `+4 count`.
    * Does not drive the analog lane (`gear + 5756 - 1`), and logs once per song to `stderr` if that lane contains playable notes (`type == 1`).
  * Added `redmp2_autoplay_probe` verifying non-gameplay passthrough, 4B/5B/6B/8B layouts, 5B `[3]` clearing and custom key-config tracking, single-frame press/release, back-to-back notes, long-note hold/release, and pause recovery.
* `src/app/settings_ui.h`, `src/app/settings_ui.cpp`, `src/app/main.cpp` (`a532389`):
  * Added the `Autoplay` checkbox and description at the top of the `Input` tab and the top-right `AUTOPLAY` badge during gameplay (starts off each run, not saved to `redmp2.ini`).
  * Added `--autoplay` CLI option and wired `repsp::hle::ctrl::SetButtonFilter` (cleared on exit/error paths).
* `README.md` (`e9e57c5`): Documented `Autoplay`, the `AUTOPLAY` badge, `--autoplay`, and the `REDMP2_MEM_DUMP` / `REDMP2_MEM_DUMP_VBLANK` diagnostic env vars in both Korean and English.
