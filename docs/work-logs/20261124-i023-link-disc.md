# 작업 로그: UMD 교체로 하는 링크 디스크 (issue #23)

설계 문서: [20261124-i023-link-disc.md](../design/20261124-i023-link-disc.md) (§5, §5.1)
분석 문서: [link-disc.md](../analysis/link-disc.md)
공유 런타임 작업 로그: `third_party/repsp/docs/work-logs/20261124-i079-umd-swap.md` (`repsp` #79, #80)

## 1. 구현 요약

* **저장 위치 통합 (`src/app/main.cpp`)**:
  * `--save-dir <dir>`의 의미를 메모리 스틱 루트(`ms0:`)로 변경(기본값 `<user_data>/ms0`).
  * `sceUtility`의 `save_root`를 `<ms0>/PSP/SAVEDATA`로 맞춰 `sceUtilitySavedata` 저장과 `ms0:/PSP/SAVEDATA/...` 직접 열람이 같은 폴더를 보도록 통합.
  * `--save-dir` 미지정 시 예전 기본 위치(`<user_data>/savedata`)에 세이브가 있고 새 위치(`<user_data>/ms0/PSP/SAVEDATA`)가 비어 있으면 최초 실행 시 자동 이전하고 로그 출력(`MigrateLegacySavedataIfNeeded`).
* **링크 디스크 후보 및 제목 수집 (`include/redmp2/dmp2_profile.h`, `src/game/dmp2/dmp2_profile.cpp`, `src/app/main.cpp`)**:
  * `ExtraDisc`에 `title`(`PARAM.SFO`의 `TITLE`) 추가.
  * 후보 목록 중 `PSP_GAME/USRDIR` 디렉터리가 있는 디스크만 OSD·자동 교체 대상으로 노출.
* **OSD `Link disc` 절 (`src/app/settings_ui.h`, `src/app/settings_ui.cpp`)**:
  * `Info` 탭 아래 `Link disc` 절 추가: 드라이브 상태(`Ready`/`Changing...`/`Ejected`), 현재 삽입 디스크 ID, 후보별 `Insert` 버튼, `Reinsert DMP2` 버튼 표시.
  * `repsp::hle::umd::IsReplacePermitted()`가 `false`이면 버튼을 비활성화하고 사유 안내 표시; 후보가 없으면 `"No link discs found in roms/."` 안내만 표시.
  * `Insert` / `Reinsert DMP2` 클릭 시 자동으로 `EjectDisc()` 후 `InsertDisc()` 실행.
* **자동 검증 CLI (`src/app/main.cpp`)**:
  * `--insert-disc <vblank>:<disc_id|main>`(반복 가능) 추가. 지정 VBlank에 `EjectDisc()` → `InsertDisc()` 수행 및 결과·거부 사유 로그 출력.
* **문서 갱신**: [README.md](../../README.md), [running-and-tracing.md](../guides/running-and-tracing.md), [link-disc.md](../analysis/link-disc.md)(실측 결과 반영).

## 2. 검증 결과

1. **DMP1(`roms/ULKS46050/`) 링크 디스크 전체 흐름 (`build/win64-release-ffmpeg`, headless)**:
   * **비허용 장면 차단**: 타이틀 화면(vblank 500) `--insert-disc 500:ULKS46050` → `EjectDisc refused (UMD replacement is not permitted by the game)`.
   * **최초 실행 추출**: `LINK DISC` → `예` 진입 시 `FILES(12)` → `GETSIZE(22)` → `MAKEDATASECURE(13)`으로 `ULKS46116DATA0/SD2.BIN`(2,272,173 B)과 `ULKS46116DATA1/SD3.BIN`(484,356 B) 생성, `READDATASECURE(15)` 및 `sceKernelVolatileMemTryLock`/`Unlock` 후 `sceUmdReplacePermit()` 확인.
   * **재실행 유지**: 생성된 `ms0/PSP/SAVEDATA`로 재실행 시 `FILES(12)`가 기존 파일을 인식해 재생성 없이 `READDATASECURE(15)`로 진행.
   * **DMP1 삽입 및 1곡 플레이**: `--insert-disc 1800:ULKS46050` → `0x01` → `0x06` → 500 ms 후 `0x32` → `CIRCLE` 확인 시 `sceUmdReplaceProhibit()` 호출, DMP1 `all.mp`·`all2.mp` 마운트 후 `ScorePlayerThread`에서 `--autoplay`로 DMP1 곡 1곡 결과 화면(`[ RESULT - 267 ms ]`)까지 완주.
   * **DMP2 재삽입 왕복 및 세이브**: DMP1 타이틀에서 `CROSS` → `CIRCLE` → `--insert-disc 2950:main` → `CIRCLE` → `sceUmdReplaceProhibit()` → DMP2 `all.mp`·`all2.mp` 재오픈 → `ULKS46116/SD.BIN` `AUTOSAVE`(15,260 B) → 타이틀 복귀(`ret 0 - FINISHE!!`).
2. **DMP1 없을 때 동작**: `roms/ULKS46116` 단독 실행 시 후보 0건으로 정상 부팅·종료(exit code `0`).
3. **CTest**:
   * 생성 코드 포함 Release (`build/win64-release-ffmpeg`): **35/35 PASS**.
   * 생성 코드 없음 Win64 Debug (임시 빌드 디렉터리, `-DREDMP2_GENERATED_DIR=<empty>`): **33/33 PASS**.
   * 생성 코드 없음 Win64 Release (동일): **33/33 PASS**.
4. **창 모드 확인**: 사용자 확인 대기(설계 §6.5).

# Work Log: Link Disc via UMD Swap (issue #23)

Design document: [20261124-i023-link-disc.md](../design/20261124-i023-link-disc.md) (§5, §5.1)
Analysis document: [link-disc.md](../analysis/link-disc.md)
Shared runtime work log: `third_party/repsp/docs/work-logs/20261124-i079-umd-swap.md` (`repsp` #79, #80)

## 1. Summary of Changes

* **Unified save location (`src/app/main.cpp`)**:
  * Redefined `--save-dir <dir>` as the Memory Stick root (`ms0:`, default `<user_data>/ms0`), with `sceUtility` `save_root` at `<ms0>/PSP/SAVEDATA`.
  * Added one-time automatic migration (`MigrateLegacySavedataIfNeeded`) from legacy `<user_data>/savedata` to `<user_data>/ms0/PSP/SAVEDATA` on first run when the new directory is empty.
* **Link disc candidate filtering (`include/redmp2/dmp2_profile.h`, `src/game/dmp2/dmp2_profile.cpp`, `src/app/main.cpp`)**:
  * Added `ExtraDisc::title` parsed from `PARAM.SFO` `TITLE`, and filtered candidates to those containing `PSP_GAME/USRDIR`.
* **OSD `Link disc` section (`src/app/settings_ui.h`, `src/app/settings_ui.cpp`)**:
  * Added `Link disc` section under the `Info` tab showing drive status, active disc ID, per-candidate `Insert` buttons, and `Reinsert DMP2` (automatically ejecting before inserting).
  * Buttons are disabled with a reason when `repsp::hle::umd::IsReplacePermitted()` is `false`; displays `"No link discs found in roms/."` when no candidates exist.
* **Automated verification CLI (`src/app/main.cpp`)**:
  * Added repeatable `--insert-disc <vblank>:<disc_id|main>` option for headless swap testing.
* **Documentation**: Updated [README.md](../../README.md), [running-and-tracing.md](../guides/running-and-tracing.md), and [link-disc.md](../analysis/link-disc.md).

## 2. Verification

1. **Full DMP1 (`roms/ULKS46050/`) Link Disc flow (`build/win64-release-ffmpeg`, headless)**:
   * **Prohibited scene check**: `--insert-disc 500:ULKS46050` on Title refused with `UMD replacement is not permitted by the game`.
   * **First-run extraction & persistence**: Extracted `ULKS46116DATA0/SD2.BIN` (2,272,173 B) and `ULKS46116DATA1/SD3.BIN` (484,356 B) via `FILES(12)` → `GETSIZE(22)` → `MAKEDATASECURE(13)`; subsequent runs detected existing files via `FILES(12)` and skipped directly to `READDATASECURE(15)`.
   * **DMP1 swap & 1-song autoplay clear**: Inserted `ULKS46050`, confirmed `sceUmdReplaceProhibit()`, mounted DMP1 `all.mp`/`all2.mp`, and cleared one DMP1 song with `--autoplay` to the result screen (`[ RESULT - 267 ms ]`).
   * **DMP2 reinsertion round-trip & save**: Exited Link Disc, reinserted `main` (`ULKS46116`), confirmed `sceUmdReplaceProhibit()`, reopened DMP2 archives, saved `ULKS46116/SD.BIN` (15,260 B) via `AUTOSAVE`, and returned to Title (`ret 0 - FINISHE!!`).
2. **Without DMP1**: Running `roms/ULKS46116` directly booted and exited cleanly (exit code `0`) with no link disc candidates.
3. **CTest**:
   * With generated code, Win64 Release (`build/win64-release-ffmpeg`): **35/35 PASS**.
   * Without generated code, Win64 Debug & Release (`-DREDMP2_GENERATED_DIR=<empty>`): **33/33 PASS** each.
4. **Windowed check**: Pending user verification (Design §6.5).
